# OpenAPI Generation

The toolkit can scan your application's routes and generate an OpenAPI 3.1.0 specification document automatically. It reads your resources, form requests, and route definitions to build the spec.

## Generating the Spec

```bash
php artisan api-toolkit:openapi
```

Options:

```bash
# Custom output path
php artisan api-toolkit:openapi --output=docs/openapi.json

# Pretty-printed JSON
php artisan api-toolkit:openapi --pretty
```

## Configuration

In `config/api-toolkit.php`:

```php
'openapi' => [
    'title'       => env('APP_NAME', 'API'),
    'version'     => '1.0.0',
    'description' => 'My API description.',
    'servers'     => [
        ['url' => env('APP_URL', 'http://localhost') . '/api'],
    ],
    'paths' => ['api/v1/*'],
    'security_schemes' => [
        'bearerAuth' => [
            'type'         => 'http',
            'scheme'       => 'bearer',
            'bearerFormat' => 'JWT',
        ],
    ],
    'security' => [
        ['bearerAuth' => []],
    ],
    'output' => [
        'path'   => public_path('openapi.json'),
        'pretty' => false,
    ],
],
```

### Paths

`paths` lists the route URIs to document, as `Str::is()` patterns. It defaults to `['*']`, every route; narrow it to keep internal or web routes out of a public spec.

### Output Options

| Option | Default | Description |
|---|---|---|
| `output.path` | `public_path('openapi.json')` | Where the generated spec file is written. |
| `output.pretty` | `false` | When `true`, the JSON output is pretty-printed. |

The `--output` and `--pretty` command-line flags override these config values when provided. If no output path is configured or passed as a flag, the spec is written to `public_path('openapi.json')` by default.

## What Gets Documented

The scanner discovers endpoints by analyzing controllers that use the `QueryBuilder` or return `SuccessResponse`/`ErrorResponse` instances. It finds each endpoint's resource, in this order:

1. An `#[ApiResource]` attribute on the controller method, or else on the controller
2. A resource class the method names, as in `->fromResource(ProductResource::class)`
3. The model a list endpoint queries, in `QueryBuilder::for(Product::class)` or a paginated `Product::query()`
4. A route-bound model parameter, such as `Product $product`, for a controller answering through the toolkit's `Response`

The last two look the model up in the map given to `Resource::map()`, and the last one is only a guess. An endpoint the generator cannot work out, such as one that creates a record, or one that answers with something other than the record it is bound to, names its resource:

```php
use BlueBeetle\ApiToolkit\OpenApi\Attributes\ApiResource;

final class CreateController
{
    #[ApiResource(ProductResource::class)]
    public function __invoke(CreateRequest $request, CreateProduct $action): Responsable
    {
        return $this->response->success($action->run());
    }
}
```

For each endpoint it generates:

- **Operation** - HTTP method, path, summary (derived from route name), and tags (from controller name)
- **Parameters** - Query parameters for filters, sorts, includes, and pagination based on the resource's `allowedFilters()`, `allowedSorts()`, and `allowedIncludes()`
- **Request Body** - For POST/PUT/PATCH endpoints, inferred from the `FormRequest` type-hint
- **Responses** - Success schema based on the resource's attributes and relationships, plus standard error responses
- **Path Parameters** - Extracted from route definitions

## Request Bodies

Request bodies come from the form request's `rules()`:

- Dotted keys become nested objects (`transport.origin.city`), and `*` keys arrays of their items (`lines.*.quantity`)
- `Rule::enum()` (with `only`/`except`), `Rule::in()` and `in:` list the allowed values; lists over 100 values are left out
- `nullable` adds `null` to the type, the OpenAPI 3.1 way
- `required_if`, `required_with` and the like are described on the field rather than marked required
- A comment above a rule supplies its description and example:

```php
return [
    /*
     * The customer's own reference for the order.
     *
     * @example PO-2026-001
     */
    'reference' => ['nullable', 'string', 'max:60'],
];
```

Rules that read context only a real request carries, such as the authenticated user, can be given a stand-in in a service provider:

```php
use BlueBeetle\ApiToolkit\OpenApi\RequestBodyBuilder;
use Illuminate\Foundation\Http\FormRequest;

RequestBodyBuilder::prepareRequestsUsing(function (FormRequest $request): void {
    $request->setUserResolver(fn () => new User());
});
```

A form request whose rules still cannot be read is documented without a body.

## Schema Inference

The `SchemaBuilder` infers attribute types from multiple sources (in priority order):

1. The resource's `schema()` method (if defined)
2. Eloquent model casts (`int`, `float`, `bool`, `datetime`, `json`, `enum`, etc.)
3. Database column types
4. Falls back to `additionalProperties: true` if nothing is available

## Example Output

For an endpoint like `GET /api/products`:

```json
{
  "/api/v1/products": {
    "get": {
      "summary": "List Products",
      "tags": ["Products"],
      "parameters": [
        {
          "name": "filter[name]",
          "in": "query",
          "schema": { "type": "string" },
          "description": "Filter by name"
        },
        {
          "name": "sort",
          "in": "query",
          "schema": { "type": "string", "example": "-created_at" },
          "description": "Sort by field. Prefix with - for descending."
        },
        {
          "name": "include",
          "in": "query",
          "schema": { "type": "string", "example": "category" },
          "description": "Include related resources. Comma-separated."
        }
      ],
      "responses": {
        "200": {
          "description": "Paginated set of `Product`",
          "content": {
            "application/vnd.api+json": {
              "schema": { "$ref": "#/components/schemas/ProductCollection" }
            }
          }
        },
        "401": { "$ref": "#/components/responses/UnauthorizedException" }
      }
    }
  }
}
```
