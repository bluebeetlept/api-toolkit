# Sparse Fieldsets

Sparse fieldsets let API consumers request only specific attributes for each resource type, reducing payload size. This follows the [JSON:API sparse fieldsets](https://jsonapi.org/format/#fetching-sparse-fieldsets) specification.

## Query Format

```
GET /api/products?fields[products]=name,price
GET /api/products?fields[products]=name,price&fields[categories]=name
```

## Automatic Filtering

Sparse fieldsets are applied automatically. When a request includes `fields` parameters, the resource's `toArray()` method filters attributes to only include the requested fields. No extra code needed in your resource.

```php
use BlueBeetle\ApiToolkit\Resources\Resource;

class ProductResource extends Resource
{
    protected string $type = 'products';

    public function attributes($model): array
    {
        return [
            'name'        => $model->name,
            'description' => $model->description,
            'price'       => $model->price,
            'sku'         => $model->sku,
            'created_at'  => $model->created_at->toIso8601String(),
        ];
    }
}
```

```
GET /api/products?fields[products]=name,price
```

```json
{
  "data": {
    "type": "products",
    "id": "1",
    "attributes": {
      "name": "Widget",
      "price": 29.99
    }
  }
}
```

The `description`, `sku`, and `created_at` fields are omitted from the response because the client only requested `name` and `price`.

## How It Works

- The resource matches the `fields` parameter key against its own type (e.g. `fields[products]` matches a resource with type `products`)
- Fields for other types are ignored (e.g. `fields[categories]` has no effect on a `ProductResource`)
- When no `fields` parameter is present, all attributes are returned
- Parsed fields are cached per request, so serializing a collection doesn't re-parse the query string for every item

## Using the FieldParser Directly

If you need to apply sparse fieldsets outside of a resource, for example in a controller or a custom transformer, you can use the `FieldParser` directly:

```php
use BlueBeetle\ApiToolkit\Parsers\FieldParser;
use Illuminate\Http\Request;

class ExportController
{
    public function __invoke(Request $request)
    {
        $parser = new FieldParser();
        $fields = $parser->parse($request);
        // For ?fields[products]=name,price:
        // ['products' => ['name', 'price']]

        $attributes = [
            'name' => 'Widget',
            'price' => 29.99,
            'sku' => 'WGT-001',
        ];

        $filtered = $parser->filter($attributes, $fields['products'] ?? null);
        // ['name' => 'Widget', 'price' => 29.99]

        return response()->json($filtered);
    }
}
```

## Behavior

- Only string values are parsed. Non-string or empty values are ignored
- Non-array `fields` parameters (e.g. `?fields=name`) are ignored
- When no `fields` parameter is present, all attributes are returned
